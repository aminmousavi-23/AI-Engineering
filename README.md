## 🎯 Purpose

The goal of this repository is simple: **learn by doing**.
Every topic I study on my AI Engineering roadmap gets practiced here in code, so that concepts turn into real, working skills.

## 📚 What's Inside


| Topic            | Description                                                    |
| ---------------- | -------------------------------------------------------------- |
| **Python**       | Practice exercises and notes while learning the language       |
| **Math for AI**  | Exercises on the mathematical foundations needed for AI and ML |
| **Data Science** | Data analysis, preprocessing, and modeling practice            |
| **Projects**     | Small end-to-end projects that connect the topics together     |


> The structure will grow and change as I progress along the path.



## 🤖 A Note on AI Assistance

I use AI tools as a learning aid (for example, for reviewing, organizing, and summarizing my work). I run, check, and try to understand the code and results myself, since the point of this repository is to learn.

## ⚠️ Disclaimer

- This repository is for personal learning and practice.
- Code may be unfinished, experimental, or not optimized.
- Results come from educational datasets and should not be used for real-world decisions.
